2. PLANTED LABEL SEMANTICS (CRITICAL) — 30% signal loss for plantations
   ──────────────────────────────────────────────────────────────────
   Location: train_on_vm.py:1068, 472-473
   
   Value map: {0:1, 1:2, 2:3}
   - Raw 0 (non-forest) → Mapped 1
   - Raw 1 (natural forest) → Mapped 2  ← INCLUDED
   - Raw 2 (planted forest) → Mapped 3  ← INCLUDED
   
   Label: (x_cat > 1) selects BOTH natural AND planted
   Should select ONLY planted for radiata preference signal
   
   Boost = sigmoid(aux_planted) * intro_ratio
   - Treats all forests equally, can't distinguish plantations
   - Radiata gets same boost at natural forests and plantations (wrong!)
   
   Fix: Use strict mode line 1062: (x_cat == 3)

───────────────────────────────────────────────────────────────────────────────

3. FREQUENCY WEIGHT CLIPPING (CRITICAL) — 20% loss signal degradation
   ────────────────────────────────────────────────────────────────
   Location: train_on_vm.py:221
   
   Actual range: 1 to 415,050 species (415,050x)
   Clipping: [0.25, 16.0] (64x range)
   
   Effect: Throws away 99.98% of frequency information
   - Rare species (count=1-100): all get weight 16.0
   - Common species (count=5,000+): all get weight 1.0-0.25
   - Radiata if ~5,000 counts: gets 13x LOWER loss weight than rare species
   
   Fix: Change line 221 from [0.25, 16.0] to [0.05, 100.0]

───────────────────────────────────────────────────────────────────────────────

4. BOOST IN TRAINING FORWARD PASS (HIGH) — 15% species preference degradation
   ──────────────────────────────────────────────────────────────────────────
   Location: train_on_vm.py:469-473
   
   Problem: Boost applied INSIDE forward pass
   logits = output_layer(x) + (sigmoid(aux_planted) * intro_ratio * boost_scale)
   
   Gradient flow:
   loss ← logits ← boost ← planted_score ← aux_planted_head
   
   Effect: Species loss backpropagates through boost, coupling it to
   auxiliary planted loss. Model learns to increase planted_score for ALL
   species rather than species-specific preferences.
   
   Fix: Move boost outside training; apply only at inference

───────────────────────────────────────────────────────────────────────────────

5. MISSING IPCC FOREST CLASS (HIGH) — 10% forest type signal loss
   ──────────────────────────────────────────────────────────────
   Location: train_on_vm.py:107 vs location_predictor_FIXED.py:425-647
   
   Training: Expects 6 categorical features (jrc_forest_type, xiao_planted,
   eco_id, biome_num, soil_texture, ipcc_forest_class)
   
   Sampling: Provides only 5 (missing ipcc_forest_class)
   
   Effect: ipcc_forest_class always 0 at inference; model can't distinguish
   forest types (tropical moist, temperate, boreal) that radiata prefers
   
   Fix: Add ipcc_forest_class sampling to location_predictor_FIXED.py

───────────────────────────────────────────────────────────────────────────────

6. RANDOM TRAIN/VAL SPLIT (MEDIUM) — 15% inflated validation metrics
   ────────────────────────────────────────────────────────────────
   Location: train_on_vm.py:783
   
   Current: np.random.permutation(n) - purely random
   Problem: No spatial stratification; occurrence data is spatially clustered
   
   Effect: Nearby points from same occurrence cluster leak between train/val
   Validation metrics overestimate generalization to new geographic regions
   
   Fix: Use geohash-based or geographic stratification

───────────────────────────────────────────────────────────────────────────────

7. INCOMPLETE FEATURE CONTRACT (MEDIUM) — 5% documentation debt
