## Interpretation

### What V4.3a tells us

1. **No-location ablation is effectively neutral on radiata rank.** V4.2=#79, V4.3a=#78. Location encoding is not the dominant bottleneck.

2. **Location encoding is neither villain nor savior.** Removing it does not help, but it also does not meaningfully hurt. The bottleneck is elsewhere.

3. **Top-rank regime is unchanged.** The broadleaf/native-heavy ranking persists regardless of whether the model has geographic identity. This means the model's failure to rank radiata highly is driven by features other than coordinate-based priors.

### Hypotheses status after V4.3a

| Hypothesis | Status |
|---|---|
| Location-prior dominance | **Not the main bottleneck** (ablation neutral) |
| Missing background negatives | **Still untested, highest priority** |
| Representation vs classifier mismatch | **Still untested** |
| Data scope / local support | **Still a factor** |
| Broken plantation supervision | **Still present, lower priority** |

### What to do next

V4.3b (reduced location frequencies) is **deprioritized** but not automatically ruled out -- reducing resolution is a different test than removing entirely. However, it is now behind:
1. **V4.4** (true background negatives) -- largest untested SINR alignment gap
2. **V4.3c** (AE/hidden-state kNN probe) -- zero-cost diagnostic on existing V4.2 model
