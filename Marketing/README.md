# Marketing Assets

This folder holds the proposal, partner, and visual collateral that was being built outside the app codebase.

## Structure

- `proposals/`
  - IKI / ILG proposal files and markdown conversions
- `consortium-partners/`
  - partner profile writeups for the consortium package
- `visuals/v3-explainer/`
  - screenshots and crops from the Treekipedia v3 explainer / progress page
- `visuals/analysis-ui/`
  - screenshots and crops from the analysis and recommender UI

App source remains in `treekipedia/frontend/`. This folder is only for marketing-facing artifacts and supporting docs.
